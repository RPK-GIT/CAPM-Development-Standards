# SAP CAP Source Map

Evidence base for the CAPM Engineering Standard. Every entry records an officially fetched SAP page, its key guidance, its authority level, runtime applicability, and version notes. **All entries verified 2026-08-11** unless stated otherwise.

> **Documentation restructure warning:** capire (cap.cloud.sap) was substantially reorganized in the **January 2026 release**. Old URLs (`/docs/about/*`, `/docs/guides/providing-services`, `/docs/guides/domain-modeling`, `/docs/guides/deployment/*`, `/docs/guides/security/aspects`, `/docs/advanced/performance-modeling`, `/docs/guides/databases-*`) return 404. This map uses the current canonical URLs. Re-verify quarterly (see [version-management](../docs/version-management.md)).

Authority legend: **REQ** = SAP-documented requirement · **REC** = SAP-documented recommendation · **MEN** = SAP mention/factual documentation. Runtime: N = Node.js, J = Java, B = Both.
